# Security at TruckFixr Fleet AI

**TruckFixr is an early-stage SaaS. SOC 2 readiness is in progress.** TruckFixr is
**not** SOC 2 compliant, SOC 2 certified, ISO 27001 certified, or HIPAA compliant.
Our controls are being aligned with the SOC 2 **Security, Availability, and
Confidentiality** trust services criteria.

## Reporting a vulnerability

Email **security@truckfixr.com** (or info@truckfixr.com) with details and steps to
reproduce. Please do not open public issues for security reports. We aim to acknowledge
within a few business days.

## Current control highlights

- **Authentication & RBAC:** session-based auth; tRPC `protectedProcedure` /
  `adminProcedure` (customer owner/manager) / `staffProcedure` (TruckFixr staff only).
- **Multi-tenant isolation:** application-layer fleet scoping on every customer-data
  query, with Postgres Row-Level Security enabled as defense-in-depth and verified by
  `scripts/verify/rls.ts`.
- **Privacy-first logging:** `server/services/observability.ts` redacts emails, VINs,
  phone numbers, JWTs, secret keys, and inline image data before anything is emitted.
- **Secrets management:** no secrets in git; production secrets are injected via Render
  environment variables; `JWT_SECRET` is generated by the platform.
- **Change management:** CI (`.github/workflows/ci.yml`) runs typecheck, tests, and a
  secret scan on every push and pull request.

## A note on compliance tooling

If StrongDM Comply (or any similar tool) is used, it serves **only as a documentation
accelerator. It does not prove TruckFixr is SOC 2 compliant or certified.**
